PROJECT DOCUMENTATION

An immersive historical letter-writing experience

Users explore the relationships of historical figures, choose a recipient and writing context, and generate a period-style letter alongside a modern interpretation of communication, etiquette, and material culture.

01Explore

Historical personas, period writing scenes, and relationship networks.

02Compose

Choose an event, tone, mood, research keywords, and recipient.

03Generate

Create correspondence through Gemini or bundled fallback templates.

04Interpret

Read a modern breakdown of materials, etiquette, speed, and sources.

How the experience works

  1. Choose a historical persona and explore their environment or network.
  2. Select a recipient, event, tone, mood, and keywords.
  3. Review the generated letter and its modern analysis.
  4. Copy the completed letter or continue refining the settings.

Technology

Interface
React 19 · TypeScript · Tailwind CSS 4
Build
Vite 6 · tsx · esbuild
Backend
Express 4 or Vercel Function
AI
Google GenAI SDK

Current boundary: The experience uses static historical data and in-memory state. It does not currently include authentication, a database, saved-letter history, live archive retrieval, or vector search. Generated letters are creative historical interpretations rather than authenticated archival transcriptions.

Core data flow

  1. Static TypeScript data and user selections are stored in React state.
  2. Persona selection creates an immediate local preview; setting changes use a 250 ms debounce.
  3. The frontend sends the writer, recipient, event, tone, mood, and keywords to the generation endpoint.
  4. The backend returns Gemini JSON when available, or follows its deployment-specific fallback path.
  5. WritingDesk presents the letter, modern analysis, historical sources, and copy action.

Deployment paths

Local / NodeExpress validates inputs, serves Vite, and can try ordered model candidates before using persona-specific templates.
VercelA serverless handler processes the same endpoint and falls back to a generic template or HTTP error.
Browser fallbackNetwork, non-2xx, or unreadable JSON responses trigger the client template generator.
